# Security policy

## Reporting a vulnerability

Please **don't** open a public issue for security problems.

Report them privately through GitHub instead:
**[Report a vulnerability →](https://github.com/elsewares/abstractica-releases/security/advisories/new)**

If you can't use GitHub, email **hello@elsewares.io** with "Security" in the subject.

Include the Abstractica version (shown in the About dialog), your operating system, and
steps to reproduce. We'll acknowledge your report, keep you updated while we work on a
fix, and credit you in the release notes if you'd like.

## Supported versions

Only the [latest release](https://github.com/elsewares/abstractica-releases/releases/latest)
receives security fixes. Please update before reporting.
