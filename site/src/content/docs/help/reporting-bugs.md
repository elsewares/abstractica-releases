How to write a bug report that gets fixed quickly.

Found something broken? **[File a bug report](https://github.com/elsewares/abstractica-releases/issues/new?template=bug_report.yml)** — the form walks you through what to include. Issues are public, so please don't paste journal text or your license key.

:::note[Being written]
This page is being written alongside the application. In the meantime, ask in [Discussions](https://github.com/elsewares/abstractica-releases/discussions/categories/q-a) — or browse the [latest release](https://github.com/elsewares/abstractica-releases/releases/latest).
:::
